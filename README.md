# 구스링 버전 2 — 서식 작성 도우미

외국인 주민이 **모국어 안내를 보며 입력하면, 한국어 원본 행정 서식에 바로 기재**되는 구스링 버전 2입니다. ([gusring_prototype](https://github.com/gusring/gusring_prototype)에서 옮겨 왔습니다.)
가족관계 신고서부터 하나씩 늘려 가고 있습니다 (지금: v1 서식 1~13, 22, 24~26, 33, 35, 36번).

## 화면 흐름
`#/` 언어 선택 → `#/list` 문서 선택 → `#/form/birth-report` 서식 작성 (`#/map` 민원실 지도)

언어 선택·문서 선택 화면과 헤더·지도는 [gusring-web](https://github.com/gusring/gusring-web)을 그대로 옮겼습니다. 헤더의 의견 보내기는 구글 폼 대신 구스링 백엔드로 보냅니다.
처음에 고른 언어로 서식 작성 화면의 안내와 라벨이 모두 표시됩니다.

## 서식 작성 화면
1. 한국어 원본 서식 이미지 위, 입력해야 하는 칸마다 번호 토글이 표시됩니다.
2. 번호를 누르면 바텀시트가 열리고, 그 칸의 의미와 작성법을 모국어(ko/en/zh/ja/vi)로 안내합니다.
3. 입력하는 즉시 한국어 서식의 해당 칸에 기재됩니다. 선택형 항목은 ○/✓로, 국가는 한국어 국가명으로 변환됩니다.
4. "완성 서식 보기"에서 이미지 저장 또는 A4 인쇄. 입력값은 브라우저(localStorage)에만 저장됩니다.
5. 여러 쪽 서식은 왼쪽 아래 「‹ 2쪽 중 1쪽 ›」으로 쪽을 넘깁니다. 번호와 이전·다음은 쪽을 이어서 셉니다(다른 쪽의 칸을 고르면 그 쪽으로 넘어감). 완성 서식 보기는 모든 쪽을 보여 주고, 이미지 저장은 쪽을 위아래로 이어 붙인 PNG 한 장, 인쇄는 쪽마다 A4 한 장입니다.

## 실행
```bash
npm install
npm run dev
```

로컬 [gusring-server](https://github.com/gusring/gusring-server)에 붙일 때 (기본은 운영 `https://api.gusring.kro.kr`):
```bash
VITE_GUSRING_API=http://localhost:4000 npm run dev
```

## 구스링 백엔드 연결
`src/lib/gusring-api.ts`는 gusring-server `examples/gusring-api.ts`와 같은 파일입니다 (gusring-web `src/shared/gusring-api.ts`와도 같음). 고칠 때는 원본을 고치고 복사합니다.
- 이용 기록: 화면 진입·언어 선택·검색·카테고리, 서식 작성 단계(`form_view` `fill_start` `field_open` `fill_preview` `fill_png_save` `fill_print` `fill_reset` `detail_time`)를 `formKey`(서식 id)·`formNo`(gusring-web 서식 번호)와 함께 보냅니다. **칸에 적은 값은 보내지 않습니다.**
- 의견 보내기: 헤더 버튼 → `POST /api/v1/feedbacks`. 서식 화면에서 보내면 서식 id·서식 번호·칸 id가 같이 갑니다.
- 운영 서버 CORS에 이 사이트 주소가 등록돼 있어야 의견 보내기가 됩니다 (이용 기록은 text/plain이라 등록 없이도 도착).

## 서식 추가하기
`src/forms/{formKey}.ts`에 `FormDef`를 하나 더 만들고 `src/forms/catalog.ts`에 v1 서식 번호(`formNo`)·카테고리·설명과 함께 등록하면 문서 선택 화면에 나타납니다. `formKey`는 영어 kebab-case(예: `birth-report`)입니다.
- 원본 이미지: `public/forms/{formKey}_ko.png`, 2쪽은 `{formKey}_ko_2.png` (파일 이름에 한글·공백 금지)
- `pages`: 쪽마다 `{ image, width, height }`. 1쪽 서식도 한 장짜리 배열
- 서식 하나를 목록의 여러 항목이 같이 쓰면 항목마다 `key`(주소·저장 이름)와 `title`을 따로 두고, 필요하면 `preset`(처음 열 때 미리 골라 둘 값)을 둡니다 (예: 24·26번 인감 신고서)

칸마다 필요한 것은
- `page`: 칸이 있는 쪽 (1부터, 없으면 1쪽). 아래 좌표는 그 쪽 이미지 기준
- `area`: 서식 이미지 위 탭 영역 (원본 이미지 픽셀 좌표)
- `input`: 입력 종류(`text` · `date` · `datetime` · `choice` · `country` · `idnum`)와 값을 쓸 위치
  - `date`: 「년 월 일」이 인쇄된 칸은 `boxes`(숫자만), 빈 칸은 `box` 하나(「1990년 1월 1일」)
  - `choice`: `multiple: true`면 여러 개 고르기 (신고인 출석여부 등)
  - `idnum`: 가운데 「-」이 인쇄된 칸은 `front`·`back`, 없는 칸은 `box` 하나(「901231-1234567」)
  - `country`: `allowKorea: true`는 등록기준지 칸(한국이면 주소 입력), `allowKorea: 'name'`은 국적 칸(한국이면 「대한민국」)
- `label` · `help`: 5개 국어 안내

`fields`의 순서가 번호와 이전·다음 순서입니다. 1쪽 위→아래, 2쪽 위→아래 순으로 둡니다. 두 사람이 나란히 있는 표(양부·양모 등)는 한 사람 칸을 다 채운 뒤 다음 사람으로 넘어가게 둡니다.

가족관계 신고서들이 같이 쓰는 칸(이름·한자·주민등록번호·등록기준지·주소·본·신고인·제출인·인구동향조사 학력)은 `src/forms/common.ts`에서 좌표만 넘겨 만듭니다. 이륜자동차 서식(37~39번)의 소유자 표와 신고인 줄은 `src/forms/motorcycle-common.ts`에 있습니다. 안내 문구도 거기서 같이 관리합니다. 주민등록표 신청서 두 가지(31·34번)가 같이 쓰는 「포함」 목록·확인사항·동의서는 `src/forms/resident-record-items.ts`에 있습니다.
- 번호 토글은 칸 이름(라벨)을 가리지 않도록 값 칸 왼쪽 위에 둡니다. 선택지 상자와 겹치면 `badge: 'margin'`(표 오른쪽 여백, 쪽마다 `marginX`), 그래도 안 되면 `badgeAt`으로 빈 자리를 직접 지정
- 칸 이름이 칸 왼쪽 위에 인쇄된 정부 서식(인감·주민등록 서식 등)은 번호를 칸 오른쪽 위에 둡니다 (`topRight`)
- ○·✓ 크기는 1190px 폭 기준이라, 좁은 쪽(841px 등)에서는 쪽 폭에 맞춰 줄어듭니다
- 글자는 칸 폭에 맞춰 줄어들고, 한 줄로 16px보다 작아지면 두 줄로 나눕니다
- 서명·날인, 공무원 기재란, 접수번호·처리란은 입력받지 않습니다

## 확인이 필요한 것
- 외국인 이름의 한글 표기 기준 (현재 안내: 여권·외국인등록증 이름을 한글로 옮겨 적기)
- 컴퓨터로 기재해 출력한 서식을 법원 송부용으로 그대로 받는지
- 출생신고서 ja 안내·선택지에 한글이 섞여 있음 (세대주 관계 예시 「홍길동 의 자」, 「息子 (자)」 등)
- **필수 표시 기준**: 서식·작성 방법에 '필수'라고 적힌 칸(10번 혼인신고서 ①②⑤⑦, 22·24·26번 신청 종류)만 필수로 두고 나머지는 모두 선택으로 둡니다(결정됨). 사망신고서의 눈표(*)는 "통계청에서도 수집하는 자료"라는 뜻이라 필수로 보지 않았습니다

### 서식별
- **1 가족관계등록 창설신고서**: 신고인 자격 「기타」의 예시(누가 될 수 있는지)는 작성 방법에 없어 안내하지 않음. 한국어 작성 방법만 근거로 함(별도 안내 이미지 1장은 서식과 같은 내용)
- **2 사망신고서**: 서머타임 기간 사망 시 「(서머타임 적용)」은 칸이 따로 없어 종이에 직접 적도록 안내함.
- **3 인지(친권자 지정)신고서**: 피인지자 성명 칸은 「(성) / (명)」이 검은 글씨로 인쇄돼 있어 그 아래 줄에 씀 — 창구에서 받아 주는지 확인 필요. ③의 ( ) 칸은 작성 방법에 적힌 네 가지(조정성립 등) 중에서 고르게 함. ⑦ 기타사항의 경우는 작성 방법의 일부만 예시로 옮김
- **5 파양신고서**: 「⑧ 신고인 출석여부」의 뜻(창구에 직접 나온 신고인)은 작성 방법에 설명이 없어 칸 이름으로만 안내함
- **6 개명신고서**, **7 성·본 변경신고서**: 서식 아래 작성 방법만 근거로 함. 7번 「본(本)」 설명(시조의 고향)은 일반 설명이라 창구 확인 필요
- **8 입양신고서**: 출석여부의 「법정대리인(①부 ②모 ③후견인)」을 「법정대리인」+「그중 부·모·후견인」 두 번 고르게 함 — 창구에서 이렇게 표시하는 게 맞는지 확인 필요. 신고인 전화·이메일은 칸 높이가 낮아(27px) 사람마다 번호 하나로 함께 받음
- **9 친양자 파양신고서**: 「종전의 성·본」(지금까지 쓰던 것)과 「부활된 성·본」(파양으로 다시 쓰는 것)의 뜻은 작성 방법에 설명이 없어 칸 이름으로 풀어 안내함 — 창구 확인 필요. 양친 출생연월일 칸이 좁아(약 100px) 글자가 작음
- **10 혼인신고서**: 작성 방법의 「①·②·⑤·⑦란은 신고인 모두가 기재」에 따라 그 칸들(한자·본·전화 제외)을 필수로 둠. 증인은 성인 2명. 동의자의 「후견인」 주민등록번호 칸에는 「-」이 없어 한 줄로 씀
- **11 등록부정정신청서**: 841×1190 원본이라 다른 서식보다 해상도가 낮음. 2쪽(별지)은 사건본인 5명분 — 6명 이상이면 종이를 더 붙여야 함(안내 없음). 서식 위 「(신청일)」 라벨은 신고서와 달리 「신청하는 날짜」로 안내
- **12 이혼신고서**: 미성년 자녀 4명까지(서식 칸 수). 5명 이상은 별지에 적어 간인하라고 안내만 함. ④의 ( ) 칸 선택지는 작성 방법 문구 그대로(「화해권고결정」)
- **13 창성신고서**: v1 제목은 「창성신고서」, 원본 서식 제목은 「국적취득자의 성·본 창설신고서」. 작성 방법만 근거로 함
- **21 국내거소 이전신고서**: 한국어 작성 방법 이미지가 없어 서식에 인쇄된 안내(한글 또는 영문 작성, 거주 형태 표기, 첨부서류, 위임장)만 근거로 함. 한글·영문 모두 쓸 수 있는 서식이라 이름·주소 칸에 한글 경고를 두지 않음
- **22 인감보호 신청서**: 아래쪽 「주민등록번호:」「주소:」 줄은 「대리인:」 바로 아래에 있어 대리인의 것으로 안내함 — 창구 확인 필요. 재외공관·수감기관·관계공무원 확인란과 그 안의 [ ] 표시는 기관이 하는 것으로 보고 입력받지 않음(작성방법 5·6번 참고)
- **24·26 인감 신고서**: 두 항목의 원본 이미지가 같아 서식 하나로 만듦. 작성방법에 「인감 변경신고는 별지 제9호서식을 이용」이라고 적혀 있어, v1 24번 설명(새 인감 등록·변경)과 이 서식이 맞지 않음 — 24번에 맞는 인감신고서 원본이 생기면 바꾸는 게 좋음. 24번은 「신고사항의 변경」을 골라 둔 채로 엶. 「서면신고 사유」·「증명자료」는 작성방법에 설명이 없어 칸 이름으로만 안내함
- **25 인감증명 위임장**: v1의 2쪽 이미지가 앞쪽과 같은 파일이고 실제 뒤쪽은 유의사항뿐이라 1쪽 서식으로 만듦
- **31 주민등록표 열람·등초본 교부 신청서**: 3쪽은 유의 사항뿐이라 1·2쪽만 씀. 신청인(개인)·(법인)·교부대상자를 모두 한 화면에 두고 안내로만 구분함(법인은 법인이 신청할 때만, 대상자는 본인 것이 아닐 때만). 2쪽 「신청인 (서명 또는 인)」 줄은 서명란이라 이름도 입력받지 않음. 초본 3·8번 제한(유의 사항 7)은 안내로만 알림
- **32 주민등록신고서**: 신고사항 표는 서식 칸 수대로 4명까지. 한 줄을 「관계·이름·한자·성별」, 「주민등록번호」, 「국내거소신고번호·외국인등록번호·등록기준지」 세 칸으로 나눠 받음(번호는 왼쪽·오른쪽 여백). 위임장은 세대주가 맡길 때만 쓰도록 안내함. 아래 「주민등록신고 확인서」는 공무원이 적는 곳이라 입력받지 않음
- **34 주민등록표 신청서(위임용)**: 한국어 작성 방법 이미지가 없어 서식 뒤쪽에 인쇄된 유의 사항만 근거로 함. 「포함」 목록·확인사항·동의서는 31번과 문구가 같아 `resident-record-items.ts`를 함께 씀. 위임받은 사람 주소의 번호는 칸 안에 빈 자리가 없어 오른쪽 여백에 둠
- **33 주민등록증 분실신고서**, **35·36 발급·재발급 신청서**: 주민등록증은 한국 국적자(재외국민 포함)용 서식 — 외국인 주민에게 필요한 외국인등록증 관련 서식은 아님. 35·36의 「본인 확인」(담당 공무원·통장·이장·가족·증명 가능 서류) 칸은 작성 방법상 신청인이 비워 두거나 특별한 경우에만 쓰는 칸이라 입력받지 않음. 주소 「(시·도)」 앞 칸이 좁아 「서울」처럼 짧게 적도록 안내함
- **37·38·39 이륜자동차 사용·사용폐지·신고사항변경 신고서**: 한국어 작성 방법 이미지가 없어 서식에 인쇄된 칸 이름·첨부서류·유의사항만 근거로 함. 소유자 「주민등록번호(법인등록번호)」 칸에 외국인이 외국인등록번호를 적는지는 서식에 없어 안내하지 않음 — 창구 확인 필요. 아래 「신고인(신청인) 성명」은 소유자 이름 가져오기를 두었지만, 소유자가 아닌 사람이 신고할 수 있는지는 서식에 없음
- **40 자동차양도증명서(직접 거래용)**: 한국어 작성 방법 이미지가 없어 서식에 인쇄된 조항(제1~9조)·유의사항만 근거로 함. 이륜자동차가 아닌 자동차 전반의 서식(v1 분류는 VEHICLE). 표 한 줄이 28px라 번호를 칸 오른쪽 끝에 두고 홀수 줄은 비켜 놓음(오른쪽 칸은 표 밖 여백). 수입인지 칸은 입력받지 않음. 외국인등록번호 안내는 37~39와 같은 이유로 하지 않음
- **41 이륜자동차 사용신고필증 재교부신청서**: v1 원본이 1996년 승인된 옛 서식(「96.10.4 승인」, 자동차관리법시행규칙 제102조제1항)이라 지금 창구에서 쓰는 서식과 다를 수 있음 — 현재 서식 원본이 있으면 바꾸는 게 좋음. 서식에는 「수수료 없음」이 인쇄돼 있는데 v1 설명에는 700원으로 되어 있음. 주소 칸이 낮아 긴 주소는 두 줄로 작게 들어감
